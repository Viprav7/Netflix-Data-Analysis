# Netflix Data Analysis

This project analyzes Netflix movies and TV shows using Python.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Key Insights
- Drama is the most common genre
- Netflix content increased rapidly after 2015
- Most movies are 90–120 minutes long

## Visualizations
- Content added per year
- Top 10 genres on netflix
- Rating distrubtion across 10 genres Heatmaps
- Movie Duration Distribution by Rating
- Movie Duration Distribution on Netflix
